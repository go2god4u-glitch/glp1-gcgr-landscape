SCOPE

포함·분류 기준

  • 플랫폼: 기전(mechanism)이 다른 약물도 같은 자산–임상–결과 형식으로 추가할 수 있는 경쟁 원장. 특수 약물 if 분기 금지.
  • 기전 축: 자산마다 mechanism 라벨(예: GLP-1R/GCGR dual, triple). 비교표 상단 기전 필터로 범위를 조절한다. class라는 별도 축은 쓰지 않는다.
  • 현재 경쟁군(core): 사람 임상 진입 후 현재·최근 적극 개발 근거가 있는 자산. 초기 큐레이션 중심은 GLP-1R/GCGR dual. [CLASS-REVIEW]
  • 관찰군(watch): 고정용량 복합제, 공개 데이터 제한, 후속 전략 불명확 자산. [PB-ABSTRACT]
  • 중단군(historical): 사람 임상 후 중단·휴면·비활성 자산(학습용 유지).
  • 현재 미큐레이션(추가 가능): triple·mono·amylin 등은 스키마상 추가 가능. 넣기 전에는 표에 없고, 넣을 때는 docs/PLATFORM_SCHEMA.md 체크리스트를 따른다.
  • 결과 공통 슬롯: 체중·간·GI 발생·중단. 기전과 무관. 값 없으면 공개값 없음. GI에 중단 수치 금지.
